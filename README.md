# Reeelz

Нативный Android-редактор: Kotlin, Jetpack Compose, Material 3, Media3 1.7.1 (ExoPlayer и Transformer), Coroutines, ViewModel. Минимальная версия Android 10 (API 29), compile/target SDK 35.

## Возможности

Интерфейс оформлен в фирменной тёмной стилистике Reeelz: SVG-логотип, Google Sans, стартовый экран, графитовые поверхности, сиреневые акценты, крупная типографика и вертикальный 9:16 preview. Главная использует реальные обложки проектов, поэтому декоративные фоновые фотографии в APK не добавлены. Google Sans v14 включён из официального проекта Google Fonts; лицензия находится в `GOOGLE_SANS_LICENSE.txt`.

1. **Проекты.** Главная показывает отдельные черновики с названием, обложкой и датой изменения. Можно продолжить, переименовать или удалить проект. Новый ролик создаёт отдельный проект. Старый одиночный черновик доступен как «Сохранённый ролик».
2. **Обрезка.** Лента миниатюр, перемотка, шаг ±100 мс, два маркера и ввод точного времени начала/конца. Минимальный отрезок — 100 мс (для более короткого видео — вся длительность). Preview зацикливает выбранный отрезок.
3. **Текст.** До пяти надписей: содержание, размер, цвет, положение, выравнивание строк, тёмная подложка и интервал появления. Время надписей отсчитывается от начала обрезанного ролика. Выбранную надпись можно перемещать на canvas.
4. **Звук.** Громкость исходного видео, отключение звука и одна музыкальная дорожка из системного выбора файлов с отдельной громкостью. Короткая музыка повторяется до конца ролика; длинная обрезается. Музыка начинается с начала итогового ролика.
5. **Надёжность.** Автосохранение параметров, атомарная запись черновика, независимые копии исходников, отмена экспорта с очисткой временного файла, проверка свободного места и очистка незавершённой публикации после перезапуска. Миниатюры и размеры текстовых изображений ограничены для экономии памяти.

Сохраняются crop, zoom 1–4× и положение внутри canvas 9:16, отмена/повтор последних 50 действий, экспорт MP4 H.264/AAC 1080×1920 в `Movies/Reeelz`, просмотр и отправка готового файла через Android.

## Запуск

1. Откройте корень репозитория в Android Studio с поддержкой AGP 8.9.2.
2. Установите JDK 17 или 21, Android SDK Platform 35 и Build Tools 35.0.0.
3. Укажите SDK через `ANDROID_HOME` или локальный `local.properties` (`sdk.dir=...`).
4. Выполните Gradle Sync, выберите эмулятор/устройство Android 10+ и запустите `app`.

Windows:

```powershell
./gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

macOS/Linux:

```sh
sh ./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. Gradle wrapper 8.11.1 включён в репозиторий. `local.properties`, `build/`, `.gradle/`, `.tools/`, ключи и секреты исключены через `.gitignore`.

Если Java на Windows сообщает `Unable to establish loopback connection`, задайте `JAVA_TOOL_OPTIONS=-Djdk.net.unixdomain.tmpdir=<существующий короткий локальный каталог>`. Это настройка локальной среды.

## Архитектура

- `MainActivity`, `ui/ProjectsHome`, `ui/editor/*`: Compose-интерфейс и системные picker. Transformer не вызывается из Composable.
- `EditorViewModel`, `EditorUiState`: параметры проекта, события, история действий и координация сохранения/экспорта.
- `ProjectStore`, `DraftStore`, `CaptionPersistence`: отдельный каталог каждого проекта, приватные копии видео/музыки и `AtomicFile` для параметров. Изменения non-destructive: исходный файл пользователя никогда не меняется.
- `EditorPlayback`: ExoPlayer видео и отдельный ExoPlayer музыки; управление воспроизведением отделено от UI.
- `EditEffects`, `CaptionEffect`: crop, итоговый размер и надписи для preview и экспорта.
- `ExportComposition`, `GainAudioProcessor`, `ExportEngine`: сборка видео/аудио, громкость, Transformer на главном потоке, публикация через MediaStore.
- `ExportRecovery`, `StorageChecks`: восстановление незавершённого экспорта и контроль свободного места.

## Проверки

Локальные unit-тесты проверяют геометрию crop/надписей и историю изменений. Android-тесты проверяют сохранение и независимость проектов, совместимость старого черновика, реальный экспорт с музыкой и временем появления текста, отмену экспорта длинного источника и действия с результатом.

На запущенном эмуляторе:

```powershell
./gradlew.bat :app:connectedDebugAndroidTest
```

Тест `recoveryAcrossProcessStop` требует отдельного запуска с фазами и по умолчанию пропускается. Обычная проверка пересоздания хранилища выполняется автоматически.

## Ограничения

Один видеоклип на проект, до пяти надписей и одна музыка. Нет переходов, фильтров, облака, авторизации и AI. При экспорте приложение нужно оставить открытым: фонового сервиса нет. После принудительного завершения экспорт не продолжается, но сохранённый проект можно открыть и экспортировать заново. Удаление приложения удаляет приватные черновики.

Preview музыки синхронизируется с видео с допуском 100 мс; экспорт смешивает дорожки средствами Media3. Шаг перемотки 100 мс не является покадровым монтажом. Аппаратные кодеки и производительность на реальном телефоне требуют отдельной проверки. Неподдерживаемый экспорт 1080×1920 возвращает ошибку без молчаливого уменьшения разрешения.
